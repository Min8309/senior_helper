# 시니어 헬퍼 프로젝트 발표 자료

2026년 10월 19일 제작한 26장 발표 자료입니다. `where_u_go.pptx`의 기획·구조·실제 코드·검증·로드맵 설명 방식을 참고하고, 첨부된 기존 시니어 헬퍼 HTML과 현재 저장소 코드를 분석해 작성했습니다.

## 파일

- `senior-helper.pptx`: 텍스트·도형·코드 해설을 편집할 수 있는 원본. 핵심 코드의 GitHub 링크와 숏폼 버튼·QR을 포함합니다.
- `senior-helper.pdf`: PPT에서 변환한 26쪽 PDF. 외부 링크를 유지합니다.
- `index.html`: 슬라이드 선택, 방향키 이동, 전체 화면, 파일 다운로드를 지원하는 미리보기입니다. 로컬 Vite에서는 `/presentation/index.html` 경로를 사용합니다.
- `preview.jpg`: 전체 슬라이드를 한눈에 보는 이미지입니다.
- `slides/`: PDF에서 렌더링한 슬라이드별 미리보기 이미지입니다. `index.html`과 함께 유지해야 합니다.

대표 색상은 포레스트 그린 `#26734D`, 웜 아이보리 `#FFFDF7`, 골드 `#F3B64B`입니다. 본문은 Noto Sans CJK KR, 코드는 DejaVu Sans Mono를 사용했습니다. PDF는 글꼴이 포함된 배포용 자료이며, PPT 편집 시 같은 글꼴을 사용하면 레이아웃을 유지하기 쉽습니다.

## 분석·검증 범위

- 소스 기준 커밋: `4f16596df5a2f06362b608768274bccaaff6389c`.
- 코드 발췌는 해당 파일과 줄 번호를 표시했습니다. 긴 줄은 가독성을 위해 줄바꿈했으며 일부 구간만 제시합니다.
- 같은 코드 기준에서 `npm run build:deploy`와 `npm test`가 통과했습니다. 브라우저 20건, 보안·배포 3건이며 일부 외부 응답과 장치 API는 모킹합니다.
- 일반 대화는 준비된 응답입니다. 사진 분석 백엔드·실제 비전 모델·Supabase 운영 설정과 사용자의 임상 효과를 확인한 자료로 표현하지 않았습니다.
- 목표 지표는 향후 측정 계획이며, 사용성 평가 결과나 이미 달성한 성과 수치가 아닙니다.
- 홈 화면은 첨부 HTML의 기존 예시를 사용했으며 날씨 값은 샘플입니다. 훈련 화면은 현재 로컬 실행에서 촬영했습니다.
- 제공된 로고는 편집 가능한 이미지 파일로 전달되지 않아 이번 파일에는 텍스트 브랜드명을 사용했습니다.
- 숏폼은 사용자가 제공한 링크를 버튼과 QR로 연결했습니다. 영상 내용 자체를 재생·검토한 것으로 서술하지 않았습니다.
